# Personas

## Developer

Wants to create a useful agent quickly, import skills, add tools, and run tasks locally.

Needs:

- Simple CLI.
- `AGENTS.md`-style guidance.
- Skills from GitHub.
- Safe sandbox defaults.
- Clear traces when things go wrong.

## Platform engineer

Wants to manage tools, policies, extensions, and runtime reliability.

Needs:

- Tool catalog.
- Policy engine.
- Runtime contracts.
- Observability.
- Versioned revisions.

## Security engineer

Wants to prevent prompt injection, tool misuse, secret leakage, malicious skills, and unsafe automation.

Needs:

- Threat-to-control matrix.
- Skill supply-chain controls.
- Tool risk classification.
- Policy gates.
- Eval gates.

## SRE

Wants incident triage agents that collect evidence, build timelines, and recommend safe next actions.

Needs:

- Metrics/logs/deployment/runbook tools.
- Evidence-backed conclusions.
- Approval for remediation.
- Audit trail.
