# Context Budget and Progressive Disclosure

## Purpose

Avoid loading everything into context.

## Progressive disclosure rules

```text
Guidance files: concise and loaded early
Skill catalog: load name/description/path only
Skill body: load only when selected
Memory index: load concise index
Memory topic files: read on demand
Knowledge docs: retrieve snippets only
Long history: compact and rehydrate essential guidance
```

## Required invariant

```text
After compaction, active agent snapshot, project guidance, selected skills, and policy context must be rehydrated.
```
