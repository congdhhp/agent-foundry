# Evidence and Verification

## Evidence object

Evidence supports claims, observations, and recommendations.

Evidence may come from:

```text
tool result
retrieved document
log snippet
metric result
deployment event
approved human input
test output
```

## Verification

Verifier should check:

```text
output schema
evidence presence
claim/evidence consistency
sensitive data leakage
unsupported root-cause claims
policy annotation for recommendations
confidence calibration
```

## Rule

```text
No important factual, operational, financial, compliance, security, or production-impacting claim without evidence.
```
