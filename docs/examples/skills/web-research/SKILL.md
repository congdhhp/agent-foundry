# Web Research

## Workflow

1. Clarify the research question.
2. Search for relevant sources.
3. Prefer primary and authoritative sources.
4. Read and extract relevant evidence.
5. Compare claims across sources.
6. Separate facts, interpretations, and recommendations.
7. Produce a cited answer.

## Output requirements

- Cite sources or evidence IDs.
- Do not overstate claims.
- Mention uncertainty when evidence is weak.
