# Engineering Plan

## Build order

1. Core domain types and schemas.
2. Local storage and manifest validation.
3. Snapshot resolver.
4. Guidance and memory loaders.
5. Skill and command loaders.
6. Tool catalog and tool executor.
7. Policy engine and obligations.
8. Runtime graph.
9. Evidence manager and verifier.
10. Eval runner.
11. Reference agents.
12. Revision promotion flow.

## Avoid early over-engineering

Do not build full SaaS/multi-tenant control plane before the local executable MVP proves the model.
